# Sum Of Two Integers

- **LeetCode**：[#371 Sum Of Two Integers](https://leetcode.com/problems/sum-of-two-integers/)
- **难度**：Medium
- **标签**：Bit Manipulation · Math

## 题目

Given two integers a and b, return the sum of the two integers without using the operators + and -.

**Example 1**：
**Input**：a = 1, b = 2
**Output**：3
**Example 2**：
**Input**：a = 2, b = 3
**Output**：5


**Constraints**：

-1000 <= a, b $\le 1000$
