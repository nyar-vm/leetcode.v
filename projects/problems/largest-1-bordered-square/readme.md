# Largest 1 Bordered Square

- **LeetCode**：[#1139 Largest 1 Bordered Square](https://leetcode.com/problems/largest-1-bordered-square/)
- **难度**：Medium
- **标签**：Array · Dynamic Programming · Matrix

## 题目

Given a 2D grid of 0s and 1s, return the number of elements in the largest square subgrid that has all 1s on its border, or 0 if such a subgrid doesn't exist in the grid.\r
\r
\r
**Example 1**：\r
\r
\r
**Input**：grid = [[1,1,1],[1,0,1],[1,1,1]]\r
**Output**：9\r
\r
\r
**Example 2**：\r
\r
\r
**Input**：grid = [[1,1,0,0]]\r
**Output**：1\r
\r
\r
\r
**Constraints**：\r
\r
\r
1 $\le \mathrm{len}(grid)$ $\le 100$\r
1 <= grid[0].length $\le 100$\r
grid[i][j] is 0 or 1\r
