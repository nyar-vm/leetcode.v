# Integer Break

- **LeetCode**：[#343 Integer Break](https://leetcode.com/problems/integer-break/)
- **难度**：Medium
- **标签**：Math · Dynamic Programming

## 题目

Given an integer n, break it into the sum of k positive integers, where k $\ge 2$, and maximize the product of those integers.
Return the maximum product you can get.

**Example 1**：

**Input**：n = 2
**Output**：1
**Explanation**：2 = 1 + 1, 1 × 1 = 1.

**Example 2**：

**Input**：n = 10
**Output**：36
**Explanation**：10 = 3 + 3 + 4, 3 × 3 × 4 = 36.


**Constraints**：

2 <= n $\le 58$
