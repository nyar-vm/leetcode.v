# Base 7

- **LeetCode**：[#504 Base 7](https://leetcode.com/problems/base-7/)
- **难度**：Easy
- **标签**：Math

## 题目

Given an integer num, return a string of its base 7 representation.

**Example 1**：
**Input**：num = 100
**Output**："202"
**Example 2**：
**Input**：num = -7
**Output**："-10"


**Constraints**：

-107 <= num $\le 107$
