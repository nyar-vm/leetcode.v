# Count Substrings Starting And Ending With Given Character

- **LeetCode**：[#3084 Count Substrings Starting And Ending With Given Character](https://leetcode.com/problems/count-substrings-starting-and-ending-with-given-character/)
- **难度**：Medium
- **标签**：Math · String · Counting

## 题目

You are given a string s and a character c. Return the total number of substrings of s that start and end with c.

**Example 1**：

**Input**：s = "abada", c = "a"
**Output**：6
**Explanation**：Substrings starting and ending with "a" are: "abada", "abada", "abada", "abada", "abada", "abada".

**Example 2**：

**Input**：s = "zzz", c = "z"
**Output**：6
**Explanation**：There are a total of 6 substrings in s and all start and end with "z".


**Constraints**：

1 $\le \mathrm{len}(s)$ $\le 105$
s and c consist only of lowercase English letters.
